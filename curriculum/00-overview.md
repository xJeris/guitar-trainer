# Guitar Curriculum — Overview

## Gear
- Electric guitar
- Practice amp
- A USB audio interface (guitar → interface → computer, also usable for silent practice with
  headphones) or, at minimum, a microphone near your amp for the practice app's listening features

## Philosophy
You don't need music theory to learn guitar. This curriculum is **chords and songs first**.
Theory shows up only when it makes the next physical thing easier — e.g. "these two chords
share two fingers" is useful; "this is the Mixolydian mode" is not, yet.

## Structure
Each stage is a folder: `01-foundations`, `02-open-chords`, `03-strumming`, etc.
Each stage has:
- A short list of goals (what you should be able to *do*, not know)
- Drills (use the practice app: tuner, metronome, chord-recognition)
- 1-2 songs that use only what you've learned so far

## Pace
No fixed timeline. Move to the next stage when the current one feels boring, not when it feels perfect.
Rough guide for someone practicing ~20-30 min/day:
- Stage 1 (Foundations): 3-7 days
- Stage 2 (Open chords): 2-4 weeks
- Stage 3 (Strumming + first songs): ongoing alongside Stage 2

## How to use this curriculum
- Adjust the plan to what's actually hard for you, don't just push through more content — if a
  drill isn't clicking, spend more time on it before moving on.
- If a chord or transition is physically painful (not just hard) — that's a hand-position problem.
  Stop and fix your grip/posture, don't push through pain.
