# Stage 1 — Foundations

Goal: comfortable holding the guitar, tuned up, and making a clean single note ring out.
No chords yet. This stage is about the physical setup so everything after doesn't fight you.

## 1. Setup & posture
- Sitting, guitar on right leg (or left if left-handed... though you likely play right-handed even if left-handed dominant — just go with what feels natural holding it)
- Neck angled slightly up, not flat/horizontal
- Strumming arm rests over the body, not gripping it
- Fretting hand thumb sits behind the neck, roughly opposite your middle finger — not wrapped over the top

## 2. Tuning
- Standard tuning, thickest to thinnest string: **E A D G B E**
- Use the practice app's tuner (via your mic or audio interface input) every single session before playing anything else
- Out-of-tune practice trains your ear wrong — don't skip this

## 3. Fretting a clean note
- Press *just behind* the fret wire (not on top of it, not far behind it)
- Use fingertip, not the flat pad — arch your fingers
- Press only as hard as needed to stop buzzing — new players grip way too hard, which tires you out and slows chord changes later
- Drill: fret each string at frets 1-5 with each finger (1=index, 2=middle, 3=ring, 4=pinky), pick it, listen for a clean ring with no buzz or mute

## 4. Picking
- Alternate picking: down, up, down, up
- Rest the pick lightly between thumb and index finger
- Drill: pick each open string slowly and evenly, then with alternate picking

## Goals to move on
- [ ] Can tune the guitar unassisted using the app
- [ ] Can fret any string/fret 1-5 cleanly with any finger, no buzz
- [ ] Can alternate-pick evenly at a slow, steady tempo (use the metronome at ~60bpm)

## Use the app for
- Tuner (constant use)
- Metronome at 60bpm for picking drills
- Note-recognition drill (optional): app names a string+fret, you play it, it confirms pitch match
